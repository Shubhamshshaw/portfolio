Vatsalya Circle - Family Elder-Care App

A free, ad-free Android app for families looking after ageing parents, which I designed, built, shipped and now market on my own. Check-ins for medicines, meals and walks ring like an alarm on whoever's turn it is; the family hears only when one is missed; siblings take turns; one-tap SOS alerts everyone with location; and Safety Check walks elders through suspicious calls asking for money or an OTP.

Available in English, Hindi, Bengali and Kannada. Ran a two-week closed test with 18 testers, then went live on Google Play in India, the US, the UK, Canada and Australia.

Under the hood

  • Mobile: React Native 0.87 (TypeScript) targeting Android 16, Firebase Phone Auth verified server-side, FCM push with tap-to-navigate
  • Backend: Spring Boot 3 / Java 21 API on Google Cloud Run that scales to zero; Cloud Scheduler fires due check-ins, missed alerts and SOS re-rings every minute, with row-level locks so overlapping runs never double-send
  • Data: Supabase PostgreSQL with row-level security and service-role-only access
  • AI: Gemini voice logging for activities and health readings, plus a rules-plus-model Safety Check that falls back to rules when the model is slow
  • Delivery & growth: GitHub Actions CI/CD (cloud Android builds, Artifact Registry, Cloud Run, Firebase Hosting); a website with 40 care guides, structured data and GA4
